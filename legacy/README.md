# Legacy ReScript / Reprocessing sources

This directory keeps the original ReTurbo implementation as a reference while the
game runs from the TypeScript rewrite in `/src`.

- `src/` — ReScript modules (`Car`, `Road`, `Track`, Reprocessing entry, …)
- `bsconfig.json` — original ReScript / BuckleScript config
- `index.html` — original entry that loaded `lib/es6/src/Index.js`
